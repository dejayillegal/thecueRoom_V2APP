High-level Architecture

Monorepo: pnpm + TurboRepo

apps/web → Next.js 15 (app router) + TypeScript

apps/mobile → Expo (React Native, latest SDK)

packages/ui → shared React + RN components (Tailwind/nativewind tokens), shadcn/ui for web

packages/schemas → Drizzle ORM schema + Zod validators + types

packages/config → eslint, prettier, tsconfig, tailwind, env validation (zod), design tokens

packages/utils → shared helpers (date, formatting, feature flags)

DB+Auth: Supabase (Postgres + RLS + Policies) with Drizzle migrations

API: Next.js route handlers (/api/*) + Supabase Edge Functions for cron/ingest if needed

State: React Query (TanStack) + server actions on web; RN Query on mobile

Styling: Tailwind (web), nativewind (mobile). Strict design tokens; dark theme default.

Testing: Vitest + React Testing Library (web), Playwright (E2E web), Jest + Detox (mobile E2E)

CI/CD: GitHub Actions (see below). No dependency on Replit workflows.

Performance/Quality gates: ESLint, TypeCheck, LCP budget, Lighthouse CI for web; bundle analyzer; A11y checks.
