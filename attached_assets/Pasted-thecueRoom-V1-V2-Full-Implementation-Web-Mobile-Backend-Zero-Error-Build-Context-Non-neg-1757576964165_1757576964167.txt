thecueRoom V1 + V2 Full Implementation (Web + Mobile + Backend, Zero-Error Build)

Context & Non-negotiables

Product: thecueRoom — closed, artist/DJ-only underground techno/house community (Bangalore-first), strict moderation, no mainstream/self-promo.

Platforms: Web (Next.js), Mobile (Expo React Native), Backend (Supabase + Edge Functions), Shared packages (Drizzle ORM/Zod).

Canonical logo file is logo.svg with anchored blink. Use this file verbatim; no duplicates or geometry changes.

Admin: full control to edit any content anytime; RA-inspired minimal dark UI.

Build: zero TypeScript/ESLint errors, strict typing, tests pass, CI green.

Objectives (must ALL be achieved)

Implement V1 features (MVP):

Auth & Roles: email + passkey (WebAuthn); roles artist, moderator, admin. Mandatory artist verification (AI + human).

Profiles: artist bio, socials, genres, Gig Radar (Bangalore) on profile; single account per artist (enforce).

Community Feed: posts, comments, reactions (no self-promo), moderation queue, content rules.

Curated News: RSS ingestion → dedupe → category tags (techno/house only).

Creative Tab: AI meme tool (on-device templates + text), AI cover-art generator (client-side first; server job optional).

Playlists: weekly Spotify techno/house playlists (read-only embed + metadata sync).

Admin Console: edit content, approve artists, ban, feature, manage news sources, playlist links, gig entries.

Implement V2 features (enhancements):

Personalized newsletter (weekly) for artists/DJs with global underground news by interest.

Advanced moderation: toxicity, spam, NSFW filters; auto-flag + human review.

Gig Radar improvements: filters (date/venue), deduped sources, ICS export.

Performance: image optimization, code-splitting, bundle analysis, RN Hermes.

Observability: audit logs, request tracing for Edge Functions, error reporting.

Deliver green CI with pnpm monorepo, typecheck, lint, unit tests, optional Playwright/Detox, Next.js build.

Deliver cleanup: remove random/ugly/duplicate code & assets; all references use the canonical logo.svg.

Produce a single PR with human-readable changelog, bundle reports, and docs (runbooks).

Standards: TS strict everywhere, ESLint (typescript-eslint, import, jsx-a11y, react-hooks), Prettier, commitlint (conventional).

Security: RLS policies, row-level checks by role, rate-limits, input validation via Zod, server auth guards.

Data Model (Drizzle)

users, artists, profiles, gigs, posts, comments, reactions, news_items, playlists, tracks, verifications, moderation_flags, newsletter_prefs, audit_logs.

Relations & Zod schemas generated; strict enums for genres, roles, content category.

Edge Functions (Supabase)

ingestNews: fetch RSS → normalize → dedupe (title+source+hash) → category map → insert.

newsletterWeekly: segment users by newsletter_prefs → assemble content → send (Mail provider API).

moderationGuard: toxicity/NSFW scoring (provider or heuristic) → auto-flag > threshold.

gigSyncBlr: fetch Bangalore gig sources → normalize → dedupe → index for filters.

artistVerify: webhook to record AI+human verification state transitions.

Web (Next.js)

App router; routes: /, /feed, /creative, /news, /playlists, /gigs, /profile/[handle], /admin.

Use RSC for data fetching where suitable; tanstack-query for client mutations.

Images: next/image only; SVG logo must reference public/logo.svg (no copies).

Accessibility: keyboard nav, focus styles, aria, color contrast.

Mobile (Expo RN)

Stacks: Feed, Creative, News, Playlists, Gigs, Profile.

react-native-svg for logo; one vector mapping of the logo.svg (no duplicates).

Hermes + inlineRequires; minimal polyfills; Flipper disabled in prod.

Moderation & Rules

Rule engine: “no mainstream”, “no self-promo”, bullying/abuse → auto-flag → moderator queue.

Takedown + ban flows in Admin; audit every action.

CI/CD (GitHub Actions)

Enforce pnpm@9, Node 20.x, one lockfile (pnpm-lock.yaml).

Jobs: install → typecheck → lint → unit tests (Vitest) → (optional) Playwright → build web → artifacts (bundle report).

Use the previously provided ci.yml or regenerate one with same gates.

Performance

Web: route-level code-split, image & font optimization, bundle analyzer report committed to reports/.

Mobile: Hermes, inlineRequires, remove unused polyfills/assets.

Caching headers for static assets; ISR for low-churn content.
