Advanced Repo Cleanup & Refactor

Context

Monorepo with apps/web (Next.js), apps/mobile (Expo RN), packages/* (shared), drizzle/zod schemas, Tailwind, TypeScript.

Canonical logo is logo.svg (with anchored blink). Use exactly this file; do not duplicate or alter geometry/paths/animation.

Remove ugly code / random code / dead assets and consolidate UI references. Upgrade to advanced standards without changing intended UX.

Objectives (must all be met)

Create a new branch chore/advanced-cleanup.

Enforce strict TypeScript, modern ESLint, Prettier, and consistent imports across the monorepo.

Delete unused code, assets (PNG/SVG), styles, and “demo/false” components; replace ad-hoc logic with testable, typed utilities.

Normalize UI/UX asset references so all places use the canonical apps/web/public/logo.svg (and mobile assets mirror it once). No duplicates.

Replace imperative, brittle code with composable functions, hooks, and typed services. No inlined magic numbers or TODO stubs left behind.

Ensure builds pass (web + mobile), tests pass, and bundle size is reduced (verify with reports).

Produce a single PR with a human-readable changelog and per-commit scope.

Guardrails

Never modify environment secrets.

No breaking schema or API contracts unless test-covered and noted in the PR.

If code is unreachable or unused, delete; if possibly referenced by dynamic import, convert to explicit import or add test to prove usage.

Step 4 — Dead Code & False UI Detection

Add a helper script to detect unused TS/TSX and unused assets:

// scripts/find-unused.js
import fs from 'node:fs';
import path from 'node:path';
import glob from 'fast-glob';

const root = process.cwd();
const exts = ['.ts', '.tsx', '.js', '.jsx', '.css', '.scss', '.svg', '.png', '.jpg', '.jpeg', '.gif'];

function readAllFiles() {
  return glob.sync(['**/*.{ts,tsx,js,jsx,css,scss,svg,png,jpg,jpeg,gif}'], {
    cwd: root,
    ignore: ['**/node_modules/**', '**/.next/**', '**/dist/**', '**/build/**', '**/coverage/**'],
    dot: true,
  });
}

function findReferences(files) {
  const content = files.map(f => fs.readFileSync(path.join(root, f), 'utf8')).join('\n');
  return (needle) => content.includes(needle);
}

const files = readAllFiles();
const isReferenced = findReferences(files);
const candidates = files.filter(f => exts.includes(path.extname(f)));

const unused = candidates.filter(f => {
  // Never treat canonical logo as unused
  if (f.endsWith('apps/web/public/logo.svg')) return false;
  const base = path.basename(f);
  return !isReferenced(base);
});

if (unused.length) {
  console.log('UNUSED FILES:');
  unused.forEach(f => console.log(' -', f));
  process.exitCode = 1;
} else {
  console.log('No obvious unused files.');
}


Run pnpm unused and remove the listed files after manual inspection.

Remove stubs, example/demo pages, duplicated components, and commented code blocks.

Step 5 — Advanced Refactors

Convert any anonymous default exports to named exports.

Extract business logic from components into @/lib/* with pure functions + unit tests.

Replace imperative effects with custom hooks (debounce, memoized selectors).

Standardize data fetching:

Next.js: use @tanstack/react-query or RSC patterns consistently.

RN: co-locate queries in /features/*/api.ts.

Accessibility pass: aria labels, focus rings, keyboard navigation, color contrast tokens.

Step 6 — Performance & Bundle Hygiene

Next.js (apps/web):

Enable image optimization & font optimization; audit dynamic imports.

Add next.config.mjs with productionBrowserSourceMaps: false, strict headers for caching of static assets.

Add pnpm analyze using next-bundle-analyzer; commit the HTML report to reports/.

React Native (apps/mobile):

Remove unused polyfills. Ensure babel plugins are minimal.

Turn on Hermes if not already; enable inlineRequires.

Step 7 — Testing & Type Coverage

Ensure Vitest/Jest runs for packages + apps; add missing tests for new utilities.

Add type-coverage:

Target: ≥90% type coverage on packages; ≥80% on apps (raise if easy).

Step 8 — Lint/Format/Dep Audit

Run: pnpm depcheck and remove unused deps.

Pin major versions; prefer ^ only for minors.

Fix all ESLint errors; no warnings allowed in CI.
